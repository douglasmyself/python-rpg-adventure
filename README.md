# ⚔️ Python RPG: Dungeon Quest

Um jogo de aventura textual (*Dungeon Crawler*) desenvolvido em **Python**, estruturado com Programação Orientada a Objetos (POO), lógica de combate por turnos, aleatoriedade e gestão de inventário.

## 🚀 Funcionalidades
- **Escolha de Classes:** Sistema de atributos diferenciados para Guerreiro e Mago.
- **Sistema de Combate Dinâmico:** Turnos de ataque baseados em cálculo de dano com fator aleatório (`random`).
- **Gestão de Recursos:** Sistema de poções de cura limitadas durante as batalhas.
- **Progressão de Inimigos:** Enfrente múltiplos monstros até chegar ao Chefe final da masmorra.

## 🛠️ Conceitos Aplicados
- Programação Orientada a Objetos (Classes, Construtores e Métodos)
- Estruturas de Repetição (`While`, `For`) e Condicionais
- Tratamento de escopo e manipulação de listas e dicionários
- Uso de bibliotecas nativas (`random` e `time`)

## 🔧 Como Executar
Certifique-se de ter o Python instalado e execute no terminal:

```bash
python jogo.py
